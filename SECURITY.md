# Security policy

Do not open public issues containing credentials, customer identifiers, cloud
account details, logs, topology, screenshots or vulnerability proof-of-concepts.

Report vulnerabilities privately to `thiago.g.rocha@hotmail.com` with the affected
version, impact and minimal reproduction. Revoke any credential accidentally
included in a report before sending it. Customer data must never be copied into
the repository, CI logs or public artifacts.

The production baseline and known architectural limits are documented in
`docs/PRODUCTION_READINESS.md`.
