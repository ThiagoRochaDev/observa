# Observa CLI

Command-line client for Observa FinOps governance, budgets, resource tagging,
automation approvals and multi-company/tenancy administration.

```bash
pip install observa-cli
observa --help
```

Configure `OBSERVA_URL`, `OBSERVA_API_KEY`, `OBSERVA_COMPANY_ID` and
`OBSERVA_TENANCY_ID` through the process environment or a secret manager.
