# Demonstration data and public media

Use only fictional data about TGR products for public demos, fixtures, screenshots
and videos. Follow `docs/DEMO_MEDIA_POLICY.md`. Never restore removed screenshots
or capture customer/employer/partner environments. Real integrations remain
supported; this restriction applies to demonstration content and published media.

When changing the web app, read the relevant bundled Next.js documentation in
`apps/web/node_modules/next/dist/docs/` before editing. Run the API tests after
changing mock data and web lint/typecheck after changing web code.
